# @keyda/bot-capacitor — renamed

This package is now **[@telybot/capacitor](https://www.npmjs.com/package/@telybot/capacitor)**.

```bash
npm uninstall @keyda/bot-capacitor
npm install @telybot/capacitor
```

Then `KeydaBot` → `TelyBot`. Until you do, this last release (0.2.1) forwards
everything to the new package under the old name, deprecated. It gets no
further releases.
